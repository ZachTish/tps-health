# TPS Health 0.15.5

TPS Health 0.15.5 is an emergency reliability patch for the workout exercise picker. Version 0.15.4 made the picker paint before discovery finished, but it still started a whole-vault metadata scan 100 ms after opening. Closing the picker ignored that scan's result without stopping the work, which could leave Obsidian's renderer saturated and the vault unresponsive.

## Changes

- Opening **Add exercise** performs no catalog or metadata scan.
- The empty picker remains immediately usable for typing, direct creation, or cancellation.
- Typed searches inspect only files in the configured exercise folder plus filenames that match the query.
- A newer query and modal close both abort the previous search before additional metadata inspection.
- Existing exercise recognition, result order, exact-link reuse, normalized note creation, and workout insertion behavior remain compatible.

## Compatibility and migration

- Minimum Obsidian version: 1.12.0.
- No settings migration.
- No Markdown or workout-data migration.
- No public API removal or breaking change.

## Validation

- Focused exercise-picker regressions pass, including zero-work open, bounded candidate inspection, and cancellation.
- Full declared test suite passes: 183 passed, 1 credential-gated live USDA test skipped, 0 failed.
- Separate production-mode build and isolated test-vault deployment pass.
- The versioned artifact is byte-identical to the isolated test-vault runtime; the frozen production UI is not reopened until this corrected artifact is deployed.
- Direct production deployment is performed only after the final tested artifacts are released.
