# TPS Health 4.1.0 — GCM-owned kinds for Health notes

When TPS Global Context Menu provides frontmatterKinds v2, Health uses its configured classifications for new reusable food, recipe, meal, exercise, and workout-plan notes plus food, activity, and workout records. Health's default templates add no identity tag or parallel scalar kind. Earlier tag/scalar notes remain readable through configured aliases and existing legacy readers. A missing or disabled mapping stops creation before a file is made.

The Note library settings hand off kind configuration to GCM. Food, recipe, and meal can share one visible kind-list value; Health uses the existing serving and ingredient structure to distinguish their internal behavior, including root-level v0.2 food notes. Custom templates may still author tags themselves. GCM v1 or absent GCM keeps the earlier Health identity controls. This release does not rewrite notes or run a startup repair.

This is a backward-compatible **minor** version. Minimum Obsidian remains **1.12.0**. Configure GCM 7.0.0 mappings and read aliases before the coordinated TishOS v0.2 note migration.
