# TPS Health 0.12.2

## What changed

- The active Daily Note workout card has a visible **Discard workout** action. **End workout** keeps the session and sets; **Discard workout** confirms first, then removes only the matching bounded workout block and clears the running state.
- The active-only `TPS Health: Discard active workout` command provides the same confirmed escape hatch from the command palette.
- When a dedicated workout note exists, Discard moves it to Obsidian trash rather than permanently deleting it. Surrounding Daily Note tasks, headings, and prose are preserved.
- Daily workout actions use a clean two-by-two narrow-pane layout with practical mobile touch targets.
- The public API adds `discardWorkout()` without changing existing calls, settings, or note properties.

## Compatibility

- No settings or note migration is required.
- Minimum supported Obsidian version: 1.12.0.

## Validation

- 172 of 173 declared checks passed; only the credential-gated live USDA integration check skipped.
- The production-mode build deployed to the isolated test vault. Obsidian 1.13.7 showed one `## Workout` heading, a clean two-by-two action card with a visible red-outlined **Discard workout** button, and a concise confirmation dialog with practical mobile sizing.
- The behavioral discard integration test removed the active heading, protected markers, and set rows while preserving the following Tasks section, moved the optional dedicated workout note to Obsidian trash, and cleared active state. Synthetic UI notes were moved to `_archive` after verification.
- The production Daily Note was reopened and verified to contain no workout markers or active workout state; the production runtime was not directly replaced.
