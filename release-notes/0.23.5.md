# TPS Health 0.23.5

## Immediate native dashboard updates

- Native food, activity, and workout edits now refresh the affected Daily Note from an authoritative read of exactly the changed file rather than waiting for MetadataCache to catch up.
- The update path reparses one record, invalidates only its old/new dates and kinds, and coalesces mounted-dashboard work without scanning the vault.

## Separate full-width Health blocks

- The Daily Note fenced block now renders **Macros** and **Activity** as separate Base-style regions that use the full available note width.
- **Macros** contains food totals and **Add food**. **Activity** contains activity/workout totals and the **Log activity** / **Start workout** actions.
- Existing native records, settings, APIs, Legacy storage, and Daily Note Markdown require no migration.

Minimum Obsidian: 1.12.0.
