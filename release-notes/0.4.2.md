# TPS Health 0.4.2

This patch finishes the responsive Live Preview food-log layout introduced in 0.4.1.

## Changes

- Uses one supported CodeMirror block-decoration renderer on desktop and mobile so food cards remain aligned and resize with the editor leaf.
- Gives the food title the first-line width up to right-aligned calories.
- Places serving, compact P/C/F values, and the action menu on the second line.
- Omits only zero-value optional sugar-alcohol and alcohol fields from the visual summary; core macros remain visible.
- Preserves source Markdown, nutrition totals, edit actions, settings, stored data, and plugin APIs.

## Validation

- 129 runnable automated checks passed; the credential-gated live USDA test was skipped.
- The production-mode artifact was deployed and hot-reloaded in the isolated test vault on Obsidian 1.13.7.
- Narrow/wide/narrow Live Preview resizing was visually verified with short and deliberately long synthetic food names. No food was logged and no provider was called.
- Minimum supported Obsidian version remains 1.12.0.

## Known limitations

- Physical iPhone appearance should receive the normal on-device acceptance check after the BRAT pull.
