# TPS Health 0.20.4

This patch makes the native-record workout workflow usable and removes an unconfigured exercise body template.

## Changes

- Active-workout recovery is now type-safe: only the matching `workout-session` may own the saved active session. Exercise records sharing the workout ID are never selected as the session.
- Native session notes display Health's workout action bar on desktop and mobile. The summary reads indexed native exercise/set records and refreshes after exercise or set changes without scanning the empty session body.
- Saved workout plans preload their exercises into the native session. Preload failure is contained after durable session creation, so the user can still add exercises, log sets, finish, or discard the workout.
- With no configured exercise template, new exercise notes contain Properties only. The plugin no longer inserts its own body tag, Notes heading, Cues heading, or placeholder bullet. Explicit custom templates are still honored.
- Records remain path-independent ordinary Markdown. `_records` is an optional producer default, not an identity or discovery requirement.

## Compatibility and known limitations

- Backward compatible; no settings, API, or stored-record migration.
- Existing exercise bodies are preserved and are not automatically stripped.
- Native plan preload uses the existing TPS Health workout-plan exercise list. This release does not migrate plan bodies into a new schema.
- Minimum Obsidian version: 1.12.0.
