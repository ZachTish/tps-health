# TPS Health 3.8.6 — Explicit tray actions

Food names in the logging tray no longer open the food editor when tapped. Use the row’s three-dot menu for **Edit food** or **Remove from tray**. Selecting the search field closes Review without clearing the tray or moving keyboard focus away from search.

The menu reuses the existing edit/remove paths, has a labeled 44 px touch target and keyboard focus styling, and is disabled while logging. Search dismissal changes only existing UI state; it does not rebuild rows, save settings or start a search. No settings/storage/API migration. This backward-compatible interaction correction uses a patch version. Minimum Obsidian: **1.12.0**.

Validation:

- Three new regression cases failed against 3.8.5. All 39 focused food-search cases now pass, including removal after failed Describe persistence and preserving quantity/unit/draft behavior.
- Versioned full suite: **551 passed**, zero failures/cancellations, one optional live USDA credential-dependent test skipped. TypeScript, suite build and separate final build passed.
- Test-vault deployment and named Health-only disable/load-manifest/enable reload confirmed **3.8.6** on Obsidian **1.14.2**.
- Installed UI: tapping the name did not open an editor; the native options menu opened the existing editor explicitly; Escape returned focus to the menu button and Enter reopened it; removal affected only the selected queued food. Repeated search selection collapsed Review, retained the queued items and kept focus in search, without an extra settings save.
- At **320 and 390 CSS px**, both rows had no horizontal overflow, long labels cleared the menu, and menu targets measured **44 × 44 px**. This is desktop-host narrow-layout verification; physical iPhone keyboard behavior remains device acceptance.
- QA used synthetic in-memory foods with temporary settings-save/provider adapters. It made no food-note or consumption writes, closed the temporary modal and restored all adapters and the original settings object. Seven consumer settings files remained byte-identical.

Tested in **Obsidian Plugin Test Vault** and ready for the user’s BRAT pull. Production has not been modified.
