# TPS Health 0.15.0

TPS Health 0.15.0 makes a running workout easier to find and substantially leaner to operate in a Daily Note.

## What changed

- Each workout creates one ordinary Daily Note task linking to its `## Workout` session section. It uses the workout start time for Controller/calendar-style discovery, becomes checked when the workout ends, and is removed if the session is discarded.
- Repair keeps exactly one matching task and bounded workout block. The parent task is explicitly excluded from exercise-set parsing, completion counts, and planned-set detection.
- At 520 px and wider, every set fits on one row: ordinal, previous result, weight, reps, rest, and completion. Smaller panes reflow by container width rather than app-window width.
- Minus/plus steppers no longer occupy permanent space. Numeric values remain visible, and steppers appear when their field is hovered or focused; touch devices reveal them on focus with practical targets.
- Choosing a new exercise creates or reuses its exercise note immediately and links the planned row before the first set is performed. Seeded and duplicated rows retain the link.

## Compatibility and migration

- Minimum Obsidian version: 1.12.0.
- No settings migration is required.
- Legacy active workout blocks receive the single linked task when TPS Health repairs or mutates them. Existing completed historical notes are not bulk rewritten.
- Workout set bullets remain ordinary Markdown records; the new task is navigation and scheduling metadata only.
