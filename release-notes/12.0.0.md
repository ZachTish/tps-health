# 12.0.0 — Remove daily-note rollup automation

The requested task is a one-time manual data import, not a reusable plugin feature. Removes the daily-note rollup controls, command, settings/default, event subscriber, pending-date queue, aggregate/source writers and index API added in 11.1.0. The existing nutrition logging, calculations, goal notes and five settings destinations retain the 11.0.0 behavior. No replacement importer, watcher, timer, migration or note writer is installed.

This major version removes the public 11.1.0 rollup command/API/settings surface. Older saved rollup preferences are no longer used. No note, setting file or existing daily total is automatically rewritten or removed; any one-time historical data operation is separate from this plugin release. Minimum Obsidian remains 1.12.0. Version 11.1.0 and its immutable release remain historical evidence.

Full declared suite and a separate final build are required; final artifacts are checked against the test runtime. Test-vault acceptance covers the five existing destinations, absence of the rollup command/settings/API and unchanged saved preferences/enabled state. Production remains on its existing 11.0.0 installation. No physical iPhone/iPad acceptance is claimed.
