# TPS Health 3.4.3

- A 1.1-second accent highlight fades on the existing button. Its temporary class is removed when the animation ends; repeated additions, including merged duplicates, trigger a fresh highlight.
- Search and saved draft queries still clear, quantities still merge, and scrolling remains stable.
- The mobile footer stays hidden while typing. A pending highlight starts when the footer becomes visible after keyboard dismissal; a finished highlight does not replay on later dismissals.
- Reduced-motion preferences disable the animation. Describe estimates and validation errors retain their existing review flows.
- No settings, migrations, timers, keyboard listeners or persistent UI state.

Patch release for the requested selection interaction refinement. Minimum Obsidian **1.12.0**. The existing keyboard style query still requires WebKit 18+ or a supporting Android WebView.
