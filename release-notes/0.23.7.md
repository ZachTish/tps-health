# TPS Health 0.23.7

## Derived native food nutrition

- A native food entry's linked Food, Quantity, and Unit are now authoritative. Changing Quantity from 2.5 to 3 recalculates every macro from the linked food's per-serving definition.
- Daily Macros uses the recalculated projection immediately. A short per-record debounce then writes the calculated amount and nutrient columns so ordinary core Bases stay portable and queryable.
- Editing a reusable food's serving or nutrition recalculates only entries linked to that file; warm dashboard reads still perform no vault scan.
- New native entries keep one consumed Quantity and one Unit instead of duplicating them into `servingQuantity` and `servingUnit`. Existing aliases are preserved but no longer drive calculations.
- Unlinked Quick-add/import records remain immutable snapshots because there is no linked food definition to derive from. Legacy Daily Note line logs are unchanged.

This is a backward-compatible patch. No settings migration or bulk record rewrite is required. Existing linked entries self-reconcile when indexed or edited. Minimum Obsidian: 1.12.0.
