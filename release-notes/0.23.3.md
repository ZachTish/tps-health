# TPS Health 0.23.3

## Configurable native-record identity compatibility

- Health now indexes native records through GCM `nativeRecords` API v2's canonical inspector.
- Tag-identified Health records no longer need physical `tpsId` or `tpsSchemaVersion` frontmatter properties.
- GCM v1 property identity remains supported. Health does not own, duplicate, or rewrite the configured identity profile.
- Food quantities/macros and workout sets/aggregates remain typed user data and are unchanged.

Minimum Obsidian: 1.12.0. Tag identity requires GCM 1.43.0 or newer; property identity remains compatible with older GCM v1 APIs.
