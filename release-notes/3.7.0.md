# TPS Health 3.7.0

Adds **TPS Health: Create recipe** to the command palette. Search for ingredients with the existing saved/provider food picker, choose their amounts, and save a reusable recipe. Creation opens the standard portion logger; cancel that logger to keep the recipe for later. Recipes are searchable alongside saved foods.

- **Number of servings:** divides all ingredient nutrients by the yield and calculates grams per serving when every ingredient has a supported weight.
- **Total weight (100 g portions):** calculates nutrients per 100 g from the finished weight, or from known ingredient weights.
- Optional **Finished recipe weight (g)** accounts for cooking gains/losses in either mode. Unknown weights stay unknown; millilitres are not treated as grams.
- The editor previews the serving and macros, preserves both modes when editing, and rejects invalid/nonpositive yields before writing. Fractional servings and gram amounts use the existing logger.
- Fixes recipe preparation discarding gram conversions. Existing meals remain one portion; existing count-based recipes and the legacy API yield remain compatible. The existing food tray is untouched by the command.

Minor release for a new command, recipe yield UI and backward-compatible optional `recipeTotalGrams` note/API field. No data migration or automatic note repair. Minimum Obsidian **1.12.0**.
