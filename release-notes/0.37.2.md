# TPS Health 0.37.2

TPS Health 0.37.2 fixes the remaining underestimation visible in the iPhone half-bagel screenshot.

## Fixes

- Normalizes `0.5 of a bagel…` to a clean bagel description instead of retaining `of a` in the food identity.
- Sizes an ordinary bagel with cream cheese as a composed base plus spread rather than a generic 50 g serving.
- Rejects a 100 kcal half-bagel-with-cream-cheese estimate as missing named components.
- Consults configured nutrition providers for unresolved composed dishes before accepting a free-form fallback estimate.
- Allows broad provider evidence for flavor variants while retaining strict enough component coverage to reject unrelated one-word matches.
- Explicitly includes spreads, sauces, and toppings in AI review, repair, and estimate instructions.
- Advances durable request versions so queued phone work cannot reuse the prior estimation contract.

## Compatibility

- No settings or data migration.
- Existing food notes, logs, trays, provider settings, and native-record schemas remain compatible.
- Minimum supported Obsidian version remains 1.12.0.

## Validation

- Exact screenshot phrase covered by parser, portion-weight, low-estimate rejection, provider-evidence, and end-to-end tray regressions.
- Provider suite, full declared suite, TypeScript, and a separate production-mode build run against the final versioned source.
- Final artifacts deploy only to the isolated test-vault runtime; production is not accessed.
