# TPS Health 0.30.0

## One naming rule for dated Health occurrences

- Dated Health occurrence files now use `YYYY-MM-DD - Title`. New native food, activity, workout-session, and legacy performed-exercise records follow the same rule, and new Legacy standalone workout notes use the same builder.
- Reusable food, exercise, recipe, and workout-plan definition notes remain title-only. Core Daily Notes continue to own their configured date-only paths.
- Native workout filename projection honors the explicitly selected workout/Daily Note date even when it differs from `startedAt`; the redundant date is not persisted as another frontmatter field. Generated workout titles do not repeat the same ISO date in the filename, while the saved display `title` remains unchanged.
- Native activity creation now requests a readable date-first filename from GCM API v3. The explicit readable-filename command includes existing opaque activity records.

## Conservative prior-workout repair

- **Native records: Apply readable Health filenames** can now repair the exact prior title-first generated workout form, such as `Workout 2026-08-31 07.04.md` to `2026-08-31 - Workout 07.04.md`.
- Eligibility requires a `workout-session` record whose basename exactly equals its saved title, whose title ends in strict `YYYY-MM-DD HH.mm`, and whose local date and time both match a valid `startedAt`. Missing/mismatched timestamps, custom basenames, alternate time formatting, and other manual names fail closed.
- GCM owns the atomic rename, link updates, and collision suffix. Health preserves the stable `tpsId`, Markdown body, frontmatter title, and active-workout ID/path pair. No automatic startup scan or rename was added.
- TPS Global Context Menu 1.48.1 is the paired durability fix when GCM auto-naming is enabled: it protects both native identity and existing Legacy `kind: workout` markers at the actual mutation boundary.

This is a backward-compatible naming feature. It changes no setting, record schema, stable identity, body format, or public API. Minimum supported Obsidian remains 1.12.0.
