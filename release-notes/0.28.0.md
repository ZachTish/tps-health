# TPS Health 0.28.0

## Accurate glossy-label scanning

- Adapts supported continuous focus, exposure, white balance, point-of-interest, negative exposure compensation, and zoom controls after the camera starts.
- Cycles bounded glare-reduced grayscale, auto-contrast, and thresholded center crops alongside the existing multi-angle decoder path.
- Validates UPC-A, EAN-8, and EAN-13 check digits before lookup to reject false-positive reads.
- Keeps Scan camera-first; manual UPC/EAN entry now belongs to Search, while image scanning remains in Scan.

## Faster, safer Describe

- Uses deterministic local extraction as the immediate complete first pass and normally sends one durable Gemini review request.
- Avoids repeating a failed cloud transport call for every item and retains local matching/estimation as the editable fallback.
- Pairs with TPS AI Gateway 0.4.1, which immediately executes an already-persisted durable request on an eligible requesting device while preserving restart and cross-device recovery.

This is a backward-compatible feature release. Existing settings, notes, log records, pending trays, caches, and public APIs require no migration. Minimum supported Obsidian remains 1.12.0.
