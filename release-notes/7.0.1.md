# TPS Health 7.0.1 — Simpler settings

The default **Daily logging** page now keeps appearance, the GCM Log food shortcut and the Core Daily notes handoff together. Historical Preview import, Copy into notes and conditional Mark reviewed actions live in a closed **Earlier inline logs** disclosure under **Integrations & advanced**.

**Property names** replaces 32 simultaneous mapping inputs with one selected editor. Its native grouped selector retains all **120** existing food/nutrient, activity and workout/shared mappings. Selecting a property does not enable tracking, save settings or change notes. Apply retains the existing migration preview and confirmation; the selected property survives rerenders and takes keyboard focus.

**Workouts destination** incorrectly described Health's workout-discovery folder as the destination used by Start workout. New sessions are written through GCM's shared record owner. The setting is now **Existing workout folder**, with its actual matching role explained. Library creation folders retain their behavior. Ownership copy points to **GCM → Properties → Records** for types and **GCM → Advanced** for shared IDs, timestamps and new-log destinations.

This is a backward-compatible patch. All five destinations and the default **Daily logging** route remain. Existing settings keys, defaults, button actions, goal choices, note formats, provider configuration and writer behavior are preserved. There is one disclosure level, and property selection is transient UI state. Existing Health-scoped mobile layout, native grouped selectors, wrapped labels and focus styles are reused. No new schema, automatic migration, note cleanup, scan, cache, watcher or background service is introduced.
