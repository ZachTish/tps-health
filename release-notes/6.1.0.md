# TPS Health 6.1.0 — Food providers and calorie entry

Adds optional Edamam/Nutritionix search to the shared food/recipe picker and grams/calories entry for protein, carbs, fat and alcohol. 260 alcohol kcal saves 260/7 grams; switching units preserves the amount without a modal rebuild. Source calories, unknown values and tracked-only nutrient persistence remain intact. A read-only plausibility check flags calories below the listed macros without rewriting nutrition.

New providers default off. Configure their switches and device-local App ID/API-key secret references in TPS Controller → Connections → Food databases (also reachable from Health → Integrations & advanced). Your own provider account/API plan is required; the plugin does not create or purchase one. Nutritionix fetches nutrition for one selected result, never every search row. Missing/mismatched details are rejected before saving. Existing settings routes/defaults and note schema are preserved; this is an additive minor release. No migration/backfill or new vault scan, cache, poller or retry system.

Public Michelob Ultra discovery was confirmed, with incomplete source nutrition and multiple-code Open Food Facts HTTP 503 responses during investigation. This does not establish universal provider availability. Fixture tests cover the new authenticated providers; live paid-provider and physical iPhone acceptance are not claimed.

The food amount preview also preserves unknown macros instead of displaying untracked values as zero.

Validation: native Mac command-palette → food picker → Create food saved 260 kcal and 260/7 alcohol grams, with canonical ID present and untracked protein absent. Reloaded native amount preview showed only known calories/alcohol. Grams/calories typing and round trips preserved all 103 mounted input elements and recorded zero metadata inventories, raw reads, cached reads or write attempts. All eight TPS consumers stayed enabled; seven existing saved settings files remained byte-identical and one absent settings file stayed absent; in-memory classification/folder/goal fixtures were restored and the one synthetic food archived. Native Controller Food databases panel displayed all six new controls with both providers off, without editing settings. These checks establish native Mac behavior; paid-provider HTTP fixtures are mocked and physical iPhone acceptance remains unverified.

Minimum Obsidian 1.12.0. Full declared tests, separate build, final test deployment/reload and SHA-256 hashes are recorded below. Production deployment remains a user-owned BRAT pull.

Provider contracts: [Edamam Food Database](https://developer.edamam.com/food-database-api-docs), [Nutritionix discovery](https://docx.syndigo.com/developers/docs/instant-endpoint) and [Nutritionix selected-product nutrition](https://docx.syndigo.com/developers/docs/search-item-endpoint). No browser or public proxy is used to bypass credentials or API plan limits.

A deferred-response regression reproduced a recipe picker updating its selected amount after closing. Selection now reuses its existing search token to ignore late success/errors; no new state or retry owner is added.

Custom food creation/editing and barcode/manual-label review share one macro-input renderer. The same unit conversion and native validation apply to both, while a reviewed label retains its separately reported energy. Barcode review is covered with fixtures; camera/physical-device acceptance is separate.

Final 6.1.0 validation: 844 of 845 declared checks passed, with one existing optional live-USDA skip and zero failures. Separate TypeScript/production build and test-vault deployment/reload passed. This additive minor release is ready for the user’s BRAT pull; production was not changed.

New-connector nutrient coverage: Edamam search supplies calories/protein/carbohydrate/fat/fiber per100g; Nutritionix details map calories, protein/carbohydrate/fat, fiber/sugar, sodium and alcohol where supplied. Other micronutrients remain unknown, not zero or inferred. New paid-provider acceptance requires the user’s own credentials and plan.
