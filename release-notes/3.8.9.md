# TPS Health 3.8.9 — Fixed or calculated TDEE

Energy estimate settings now offer an explicit **Calculated** or **Fixed** TDEE method. Calculated retains BMR × daily activity factor; Fixed uses the entered kcal/day target. Existing settings normalize to Calculated without a migration. Switching methods preserves the inactive input so a user can switch back without re-entering it. Both modes represent a full-day target: logged workout calories are displayed separately and are never added to either target.

The same selected target is consumed by the companion's Daily Fitness widget when TishOS 0.21.8 or later is installed. An invalid or missing fixed value remains unavailable rather than silently falling back to the calculated estimate. The plugin does not write new vault records, change intake goals, import Apple Health workouts, or modify existing food/activity transactions. Minimum Obsidian remains 1.12.0.

## Verification and limitations

- The full declared test/build suite passes 566 checks, with zero failures and one optional live USDA check skipped for missing credentials. Focused tests cover saved mode, fixed-target arithmetic, no workout double-counting, invalid/missing target, JSON normalization, and atomic rollback on a failed settings save.
- TypeScript and production bundling pass. The generated plugin is deployed only to the isolated Obsidian Plugin Test Vault; production-vault installation is not implied.
- Physical iPhone/iPad settings UI and a real cross-device fixed-target widget publication remain to be checked after the plugin and app releases are installed. The widget's calculated mode is backward-compatible with older plugin versions.

This is a source release candidate until the public plugin release is approved and published. Production remains on its existing version until the user's normal BRAT update.
