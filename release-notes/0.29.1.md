# TPS Health 0.29.1

## Native workout editing restored

- **+ Set** now appends a real editable set to the owning workout-session note immediately. It seeds useful values from the prior set but never copies completion state.
- Exercise overflow menus now move an exercise up or down and create or edit a superset from any other exercise in the workout, including a newly created exercise.
- Set overflow menus now create or edit explicit drop-set chains from existing sets or append a new linked drop set.
- Compact superset and drop-set rails/badges make the saved grouping visible in Live Preview and Reading mode.
- All four mutations serialize against the latest session record and remain inside its single `workoutData` property. Stale handles cannot overwrite a just-added exercise or set, and no per-set or per-workout exercise child notes are created.

This is a backward-compatible reliability patch. Existing workout and reusable-exercise notes, settings, storage modes, and public APIs require no migration. Minimum supported Obsidian remains 1.12.0.
