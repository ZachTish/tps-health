# TPS Health 0.12.3

TPS Health 0.12.3 makes a blank workout reliably open and remain usable on its Core Daily Note.

## User-visible changes

- Blank workout starts now activate the matching Daily Note in Live Preview even when TPS Global Context Menu initially opens it in a background leaf.
- Choosing an exercise no longer navigates to the optional dedicated workout note or opens an empty tab.
- Exercise and set mutations synchronize the visible Daily Note editor through Obsidian's supported Markdown-leaf API.
- Live Preview workout rows use a supported CodeMirror state field, eliminating the renderer failure that could hide rows or prevent Health from reloading.
- The existing mobile/narrow-pane card remains the canonical surface with **+ Exercise**, **+ Set**, **End workout**, and **Discard workout**.

## Compatibility and migration

- No settings migration.
- No note-schema migration.
- No public API change.
- Minimum supported Obsidian version remains 1.12.0.

## Validation

- Full declared suite: 173 passed, 1 credential-gated live USDA check skipped, 0 failed (174 total).
- TypeScript no-emit and diff checks passed.
- The final production build deployed only to the isolated `Obsidian Plugin Test Vault` runtime.
- Obsidian 1.13.7 QA started a blank workout away from the Daily Note, verified immediate Daily Note activation in Live Preview, added two exercises, completed a `135 lb × 8` set, retained the unrelated task outside the protected block, and discarded only the synthetic workout. The optional dedicated note was recoverably moved to Obsidian trash and active state was cleared.
- Production was not changed. This release is ready for the user's BRAT pull after publication.
