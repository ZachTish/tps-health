# TPS Health 0.19.0

This backward-compatible feature release completes the native-record Daily Note experience for food and macro logging.

## Daily nutrition

- A `tps-health-daily` fenced block renders a compact daily nutrition dashboard from Health's incremental typed-record index.
- The dashboard shows food-entry count, calories, macro and sodium totals, configured targets, and goal progress without writing duplicate totals into the Daily Note body.
- Native food creation, editing, deletion, and rename refresh the dashboard. A one-record change does not trigger a Daily Note or full-vault scan.
- The Native POC template pairs the dashboard with a core `Daily Health.base` embed filtered to the embedding Daily Note's date, so both totals and individual records are visible.

## Compatibility

- Existing record schemas, food logging, settings, legacy storage, and public APIs are unchanged.
- Existing Daily Notes opt in by adding an empty `tps-health-daily` fenced block.
- Activity goals are intentionally not shown in the food-only dashboard; activity remains available through Activity records and Bases.
- Minimum Obsidian: 1.12.0. GCM 1.38.0 or newer remains required for native-record mode.
