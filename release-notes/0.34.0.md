# TPS Health 0.34.0

TPS Health’s native Macros and Activity blocks now let you review and manage the records behind the totals without leaving the dashboard.

## Changes

- Added a compact list action to both Macros and Activity headers in Reading mode and Live Preview.
- Food contribution rows can edit the logged name, amount, unit, consumed time, note, and—when the entry is a quick estimate—its own nutrition snapshot.
- Linked food entries recalculate from the reusable food definition when their consumed amount changes; the definition itself is never modified by the log editor.
- Manual activity rows can edit type, duration, distance, steps, calories, time, and notes. Workout rows open the complete workout note.
- Remove actions archive the selected record after confirmation so the operation is recoverable and daily totals update immediately. Active workouts continue through the existing protected discard confirmation.
- Desktop controls remain visually lean, while coarse-pointer devices receive 44 px touch targets and narrow containers keep row metadata stable.

## Compatibility and migration

- Backward-compatible minor release; no settings or record migration is required.
- Existing date filters, native records, workout-session storage, and `foods:` display options continue to work. `foods: hidden` now starts the contribution list collapsed rather than making it unreachable.
- Minimum supported Obsidian version: 1.12.0.

## Validation

- Focused native-record and dashboard tests cover food/activity editing, linked-food recalculation, isolated archival, list actions, active-workout discard routing, accessibility labels, responsive layout, and shared rendering.
- Full declared suite: 272 checks; 271 passed and the credential-gated live USDA request was intentionally skipped. TypeScript passed.
- The final artifact was deployed and reloaded in the isolated Obsidian Plugin Test Vault. Interactive QA confirmed both Macros and Activity lists, compact row actions, and the food/activity editors in Reading mode and Live Preview at a narrow mobile-like pane width. The temporary native-mode settings used for QA were restored afterward.
