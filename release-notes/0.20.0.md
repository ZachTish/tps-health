# TPS Health 0.20.0

This backward-compatible feature release turns the native Daily Note nutrition dashboard into a date-aware Health mini-app.

## Daily Health actions

- **Add food**, **Log activity**, and **Start workout** are available directly in the `tps-health-daily` card.
- Every action passes the containing Daily Note's resolved date into Health's full existing workflow. Logging from a past or future Daily Note therefore targets that day instead of silently using today.
- The actions reuse Health's reviewed modals and normal native-record service. There is no duplicate write path and no generated food, activity, or workout content is copied into the Daily Note body.
- Buttons wrap in narrow panes and retain 44 px touch targets on coarse-pointer devices.

## Sectional model

- Health continues to own its specialized mini-app and typed calculations, while ordinary Markdown records and core Bases remain authoritative for storage, filtering, sorting, and individual rows.
- The Native POC documents the same boundary for future Calendar, Time Tracking, and Finances sections. Those domain slices are not bundled into Health and are not claimed as implemented by this release.

## Compatibility

- Existing record schemas, settings, public APIs, legacy storage, and `tps-health-daily` embeds remain valid.
- Native-record mode still requires GCM 1.38.0 or newer.
- Minimum Obsidian: 1.12.0.
