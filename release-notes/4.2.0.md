# TPS Health 4.2.0 — Configure native activity fields

Apple Health activity notes now have settings-backed physical keys for Activity name, Source record ID, and Flights climbed, alongside the existing Health-owned activity mappings. Changing a key in **Integrations & advanced → Health record frontmatter** previews affected notes, requires confirmation, migrates their values, and saves the new mapping only after success. A Health field-key change also preserves the authored GCM Kind list; it no longer substitutes Health's internal record name. New native records use the configured keys; GCM continues to own the Kind list.

This backward-compatible **minor** release adds three optional property-key settings with their current names as defaults. It does not automatically rewrite existing notes or change Obsidian compatibility (**1.12.0** minimum). For the coordinated TishOS v0.2 rollout, update Health before enabling the Companion app's native imports; the app reads these fields from Health settings.
