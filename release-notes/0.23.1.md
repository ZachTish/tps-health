# TPS Health 0.23.1

## Inline Native workout sets

- Active Native-record workouts now expose a persistent next-set row and directly editable saved rows. Reps, weight, unit, per-arm behavior, RPE, rest, and set type save in place without opening a modal.
- **+ Set** focuses the inline row. Choosing a new exercise returns to that row, and **Log** is the explicit commit boundary, so partially entered values never become a set by accident.
- Saved edits preserve the stable set ID and atomically recalculate set count, total reps, and total volume. Completed workouts remain read-only.
- Active controls resolve moved sessions by stable `tpsId` and repair a stale saved path.

## Mobile form repair

- The fallback add-set modal no longer inherits a desktop flex basis that stretched each field into a large blank block on phones.
- Mobile fields use natural height and the action row stays reachable above the keyboard.

## Compatibility

- No stored-record, settings, or public API migration is required.
- Legacy workout storage and completed Native workout notes are unchanged.
- Minimum Obsidian: 1.12.0.
