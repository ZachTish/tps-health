# TPS Health 0.26.3

## Empty-workout reliability

- The first inline set in a blank native workout now reuses the exercise note already attached to that workout instead of rebuilding the full vault exercise catalog. The saved set is projected back into the same workout card immediately.
- Exact exercise paths are checked before creating a note, protecting rapid repeated sets from producing duplicate exercise notes while MetadataCache is still converging.
- Active native workout cards remain mounted through a transient post-write index miss, so a successful atomic set write is not presented as a disappearing or empty card.
- Legacy workout startup now preflights its authoritative Daily Note. A failed Daily Note write or active-state save rolls back its workout block and moves any newly created standalone workout note to Obsidian trash.
- Command and modal failures are surfaced as notices and stable status text instead of unhandled UI promise errors.

The patch is backward compatible. Existing workout sessions, exercise definitions, settings, storage modes, and public APIs require no migration. Minimum supported Obsidian remains 1.12.0.
