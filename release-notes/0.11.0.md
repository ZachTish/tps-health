# TPS Health 0.11.0

## What changed

- Added **Search wider with Gemini** after the existing bounded USDA/Open Food Facts pass. The current fast local/database search remains unchanged; wider research runs only when requested.
- Added optional grounded barcode research beside the label-first barcode-miss flow. Product identity and real source links carry into review or the Nutrition Facts scanner.
- Added a strict nutrition acceptance boundary: evidence must be consistent, high-confidence, and physically coherent with macro and alcohol energy. Missing or conflicting nutrition never creates a food automatically.
- Seeded Nutrition Facts extraction with grounded product identity while keeping the photographed label authoritative for every nutrition value.

## Clubtails coverage

The regression fixture recognizes Clubtails Blue Hawaiian as a 16 oz, 10% ABV beverage but rejects a 200-calorie web listing: 473 mL at 10% ABV contains about 37.3 g alcohol, which requires about 261 calories before carbohydrate. The UI therefore prefills the identity and asks for a label photo instead of inventing a record.

## Compatibility and privacy

- Requires TPS AI Gateway 0.4.0 or newer for the wider search feature; an older Gateway fails closed with an update instruction.
- No Health settings or existing-note migration is required. The fast provider route and camera-first barcode miss remain available without grounded research.
- Grounded queries use the user's configured device-local Gemini credential through TPS AI Gateway. Grounding source links are shown for review; API keys and full provider payloads are not logged.
- Minimum supported Obsidian version: 1.12.0.

## Validation

- 167 of 168 declared Health checks passed; only the credential-gated live USDA integration check was skipped. Focused coverage includes Clubtails identity, ABV-derived alcohol energy, conflicting-nutrition rejection, safe source filtering, stable durable IDs, old-Gateway rejection, label identity handoff, and the existing food/workout/recipe contracts.
- The required final production-mode build deployed only to the isolated test runtime. Obsidian 1.13.7 hot-reloaded the plugin; a bounded `Clubtails Blue Hawaiian` USDA/Open Food Facts search returned no usable result and showed **Search wider with Gemini** as the primary fallback above secondary manual creation. No grounded call, food creation, or food log was submitted, and the pre-existing tray/search/tab state was restored.
- Production was not accessed or deployed.
