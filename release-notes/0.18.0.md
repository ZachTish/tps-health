# TPS Health 0.18.0

This backward-compatible minor release adds opt-in native Markdown storage for Health's food, activity, workout-session, and workout-exercise records. Existing vaults remain in Legacy mode.

Typed frontmatter now owns quantities, macros, workout aggregates, and atomic set lists. The Health mini-app remains the editing surface, and a dry-run/copy-only legacy importer never changes source notes.

Minimum Obsidian: 1.12.0. GCM 1.38.0 or newer is required for native mode.
