# TPS Health 0.1.4

This patch prevents preferences and volatile food/workout state from overwriting synchronized settings.

## Changes

- Reloads current plugin data and merges only locally changed keys while preserving unknown fields.
- Reconciles food/workout state and settings mutations made while a save is in flight.
- Keeps higher-schema settings read-only and preserves guarded SecretStorage migration behavior.
