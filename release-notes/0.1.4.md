# TPS Health 0.1.4

This patch prevents preferences and volatile food/workout state from overwriting synchronized settings.

## Changes

- Reloads current plugin data and merges only locally changed keys while preserving unknown fields.
- Reconciles food/workout state and settings mutations made while a save is in flight.
- Keeps higher-schema settings read-only and preserves guarded SecretStorage migration behavior.

## Compatibility and validation

- Minimum Obsidian: 1.12.0; desktop and mobile supported; no manual migration.
- Focused provider/settings tests passed with the live USDA case intentionally credential-gated; TypeScript and diff checks passed.
- Full declared suite: 100/101 passed with the single credential-gated live USDA test skipped. A separate production-mode build deployed byte-identical artifacts to the isolated test vault.
- Obsidian 1.12.7 was reloaded with **Reload app without saving**; Health registered normally and its runtime-owned `data.json` hash remained unchanged across final validation and reload.
- External nutrition providers can still return incomplete or rate-limited results.
