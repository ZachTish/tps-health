# TPS Health 0.20.1

This patch fixes native Health records being assigned to tomorrow's Daily Note when an evening local timestamp crosses midnight in UTC.

## Correct local-day routing

- Native food, activity, and workout records derive their `date` property from the user's local calendar day.
- An explicitly selected Daily Note date remains authoritative for past and future Health actions.
- Date-only values remain byte-for-byte calendar dates and are never shifted through UTC parsing.
- UTC timestamps remain unchanged for synchronization and chronological ordering.

## Compatibility

- No setting, schema, API, or legacy-storage migration is required.
- Existing records are not silently rewritten. A misdated record can be corrected by changing only its `date` property.
- Minimum Obsidian: 1.12.0.
