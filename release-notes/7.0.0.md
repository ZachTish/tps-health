# TPS Health 7.0.0 — Free food search and accurate servings

Food logging and recipe ingredients now use USDA FoodData Central and Open Food Facts alongside relevant saved foods/recipes and the existing built-in catalog. Edamam and Nutritionix HTTP adapters, enabled switches and key selectors are removed. No API signup or paid subscription is needed. USDA's free personal key remains optional; DEMO_KEY has lower limits.

- Known-brand USDA queries reserve their existing page for branded products and omit connector words consistently. Generic searches retain their dataset scope; no additional query lane or page loop.
- Open Food Facts search shows identity-only previews. Selecting one loads its current barcode record through the existing owner/cache, instead of requiring bulk hydration of the entire page. Failed/missing/mismatched product records cannot save a preview. No index nutrition is trusted as a current label.
- Michelob ULTRA Superior Light Beer is distinct from Organic Seltzer. The [manufacturer's US label](https://www.tapintoyourbeer.com/beer/en/michelob-ultra) supplies **95 kcal, 0.6 g protein, 2.6 g carbs, 0 g fat per 12 US fl oz**. Reported calories are retained. Alcohol grams are visibly estimated from 4.2% ABV; unknown micronutrients stay absent. Sizes/variants and barcode pack sizes are not guessed.
- Matching saved definitions retain priority. Complete sourced servings precede comparable incomplete community matches. Details expose trusted source links and accuracy warnings.
- A recipe's explicit yield prevents beverage-name volume inference and double scaling. Ingredient/recipe previews and saved definitions preserve unknown nutrients; linked log projections no longer turn unknown selected core nutrients into zero. Reported zeroes remain valid; existing recipe precision is preserved.

This is a **major** release because two optional integrations are deliberately retired. Minimum Obsidian: **1.12.0**. Complete historical foods/receipts remain readable. Pending Nutritionix search previews are preserved but must be reselected through a supported source or entered from the package label. Normal settings saves omit six retired keys; existing SecretStorage values are neither accessed for those providers nor deleted. No note migration, automatic repair, new cache, watcher, poller or background requests are added. Current tracked-nutrient-only writes, forward-only nutrient additions and configurable rings/bars remain supported.

Settings retain all five Health destinations and the Controller **Connections → Food databases** handoff. Only retired connector controls disappear. Opening settings performs no provider test/save. No production deployment is included; this release is tested in **Obsidian Plugin Test Vault** and ready for the user's **BRAT pull and device testing**.

## Validation

**852 passed, one existing optional live-USDA check skipped, zero failures (853 checks).** Full declared suite/TypeScript, separate final production build, test-vault deployment and named Health reload passed. Regressions cover retired request isolation, preview hydration and failure safety, barcode identity, repeated-query request counts, shared search relevance, saved-food priority, serving scaling, unknown/zero preservation and real linked-note creation.

Foreground native Mac QA searched Michelob Ultra, inspected its manufacturer source/estimate warning, and saved a 95-calorie serving. Recipe search found the saved food first; one recipe serving remained 95 kcal and two logged as 190 kcal. Four actual saved notes retained canonical IDs and omitted unknown fiber/sodium/sugar alcohol. A fresh plugin reload recognized definitions and the 95/190-calorie entries. All eight TPS consumers stayed enabled. Eight saved TPS settings files were byte-identical afterward; temporary in-memory QA settings/methods were restored and synthetic fixtures archived.

The measured native create/readback flow recorded 11 Markdown inventories, 12 raw reads, 12 cached reads, two process calls, zero modify calls and four creates. Twenty subsequent warmed local searches performed zero inventories, reads or mutation calls. These counts do not establish startup or production performance. Native catalog QA disabled external search methods in memory; live public USDA/OFF requests were checked independently with a stub vault and no device credentials. Public database availability/completeness remains outside the plugin's control. The last public-provider check received USDA DEMO_KEY HTTP 429 (the existing cooldown stopped further USDA requests), while OFF discovery and selected-product hydration returned HTTP 200; an earlier live USDA search returned matching branded milk. No device credentials were used. Physical iPhone keyboard/touch/backgrounding acceptance remains unverified.

No existing note is repaired or rewritten by installation. Downgrading may reactivate retired connector behavior if old settings are restored; it does not restore omitted settings or remove records created with 7.0.0. Preserve settings/private state when changing versions. No credentials were created, rotated or deleted.
