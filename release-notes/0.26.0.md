# TPS Health 0.26.0

## One workout, one note

- Native workout sessions now keep their ordered exercises and sets together in a single versioned `workoutData` frontmatter property. New workouts and legacy-body imports no longer create a separate note for every exercise occurrence.
- Queryable workout totals remain ordinary frontmatter: exercise count, set count, total reps, total volume, and last-set time. Reusable exercise definition notes remain separate only when they provide cross-workout defaults and history.
- Existing child-note workouts remain readable and upgrade on their next mutation or Finish. The explicit **Native records: Consolidate workouts into one note each** command copies historical data into each parent before moving redundant `workout-exercise` notes to Obsidian trash.
- Deleting a legacy parent also cleans up only its linked child records. Failed writes cannot remove source data, failed cleanup remains recoverable, and unrelated reusable exercise notes are never selected.

This is a backward-compatible native-record schema feature. Legacy storage and existing public APIs are unchanged. Minimum supported Obsidian remains 1.12.0.
