# TPS Health 3.8.5 — Skip unrelated workout rendering work

The native-workout renderer uses the existing indexed source-file membership lookup before projecting a session, avoiding repeated enumeration of every workout when reading unrelated notes.

These are backward-compatible eligibility fixes. Existing recipe controls, workout set ordering and source paths, native-session projections, settings, commands and storage remain unchanged.
