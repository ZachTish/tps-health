# TPS Health 0.15.2

TPS Health 0.15.2 brings the compact workout table from Reading mode to Live Preview.

## What changed

- Live Preview's CodeMirror workout widgets now join into one bounded exercise table instead of rendering every set as a separate bulky card.
- The first set owns the top boundary, the last set owns the bottom boundary, and intermediate sets remain flush with one another.
- The shared exercise header, five table columns, direct inputs, compact completion control, narrow-pane layout, and touch sizing remain unchanged.
- Reading mode is unaffected and continues using its existing list-row wrapper.

## Compatibility

- Minimum Obsidian version: 1.12.0.
- No settings, API, note-schema, or Markdown migration is required.
- Existing workout records and active sessions render with the corrected Live Preview layout without being rewritten.
