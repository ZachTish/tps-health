# TPS Health 8.0.0 — Remove unused logging configuration

Health no longer offers settings that only save a value without affecting the current whole-note logger.

- Removed **Set notation** from Workouts and **Workout template path** from Note library → Templates. Reusable workout-plan, exercise and food templates remain supported.
- Retired eight ineffective stored options: `appendWorkoutSummaryToDailyNote`, `defaultFoodLogSection`, `workoutLogTarget`, `workoutDailyNotePlacement`, `foodLogTarget`, `rollupHeading`, `workoutTemplatePath`, `workoutSetNotation`.
- Removed three uncalled private helpers left by the old inline writer and misleading destination fields in diagnostic logs. The earlier-log warning now points to Integrations & advanced.

This is a **major** version because it removes persisted configuration options. Minimum Obsidian remains **1.12.0**. Live settings/state schema remains version 9; no replacement configuration or migration system is introduced.

Old configuration is normalized in memory without a startup save. The existing ordinary settings-save queue omits the retired keys while merging current preferences from disk. No note or template file is changed. Active workout state, food drafts, goals, mappings, credential references, legacy private credentials and unrelated extension data keep their existing preservation rules. Future-schema settings remain read-only to older code. Old positional API arguments and historical draft context remain accepted; current logs still use the existing whole-note writer.

Historical options with real readers stay supported: `foodLogFilePath` scopes the explicitly opened historical Food Log Base, and `storageMode` is the earlier-log review state. Preview import, Copy into notes and conditional Mark reviewed actions remain. Historical source/provenance records remain readable.

The five settings destinations, default Daily logging page, single disclosure level, accessible native controls, focus behavior and mobile styles remain unchanged. Every existing explicit button action is retained.
