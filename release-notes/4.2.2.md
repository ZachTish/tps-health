# TPS Health 4.2.2

Backward-compatible completion of the whole-note logging path introduced in 4.0.0; minimum Obsidian 1.12.0.

## Change

Food picker recency and frequency now use Health's existing native food-entry index. The previous picker reread historical Daily Notes after each log and omitted current whole-note entries. Current food links, definition names/brands/barcodes, consumption times, rename, archive/unarchive and deletion now drive saved/local ranking.

Removed the obsolete picker usage cache, invalidation flags and legacy body scanner. No replacement index, watcher, persisted setting, writer or note migration. Historical inline totals and explicit import remain unchanged; inline history contributes to native ranking only after explicit import.
