# TPS Health 3.4.2

Food search now uses the space freed by hiding Review/Log while typing on mobile. The previous release hid the footer but left obsolete nested padding, including duplicated iPhone safe-area space, below the results.

- Removes the logger's generic form-modal styling and its obsolete narrow-screen content padding. The existing flex result list expands naturally.
- Reuses the existing keyboard CSS query to avoid reserving the home-indicator safe area while the keyboard is open. Dismissing the keyboard restores safe-area padding and the footer.
- Query clearing, automatic tray review, quantity editing, desktop controls and shared keyboard positioning remain unchanged. No new listeners, settings, persisted state or migration.

Patch release for a mobile layout defect. Minimum Obsidian **1.12.0**. Keyboard style queries retain the 3.4.1 requirement of WebKit 18+ or a supporting Android WebView.
