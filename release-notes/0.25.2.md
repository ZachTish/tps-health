# TPS Health 0.25.2

## Build a blank workout while it is live

- **Add exercise** now resolves the active native workout through its stable session ID before attaching the chosen exercise. A readable-filename rename or move immediately after workout creation no longer leaves the picker targeting a stale path.
- The resolved owner is persisted before mutation and rechecked after reusable-exercise creation. If Sync replaced the active workout, the stable ID is duplicated, indexing is incomplete, or the session has ended, TPS Health stops without attaching the exercise to the wrong workout.
- A zero-set exercise is projected into the live workout immediately, so its first editable set row is available without reloading the note or logging a placeholder set.

Existing workout and exercise records, settings, schemas, storage modes, and public APIs require no migration. Minimum supported Obsidian remains 1.12.0.
