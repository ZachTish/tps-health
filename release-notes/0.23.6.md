# TPS Health 0.23.6

## Independent Daily Note sections

- `tps-health-macros` is a standalone date-scoped macro section with food totals and **Add food**.
- `tps-health-activity` is a standalone date-scoped activity section with activity/workout totals plus **Log activity** and **Start workout**.
- `tps-health-daily` remains supported as the combined compatibility block for existing notes.
- Each standalone section listens only to the native record kinds it displays, avoiding unrelated rerenders.

## Phone width parity with core Bases

- Health sections now use Obsidian's own phone Base-embed width, transform, border, and callout variables. They align with adjacent core Base embeds instead of remaining inside the narrower Markdown content column.
- No fixed phone margin is encoded, so themes and Obsidian's callout override remain authoritative.

This is a backward-compatible patch. No stored record, setting, public API, or Legacy workflow migration is required. Minimum Obsidian: 1.12.0.
