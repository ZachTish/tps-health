# TPS Health 3.4.1

Selecting a food now clears the search bar and its saved tray query. On mobile Search, Review and Log foods disappear while the keyboard is open and return when it is dismissed.

- Reuses the existing search queue to cancel pending searches, invalidate stale results and restore saved/recent picks. The tray still opens, duplicate selections merge, and scroll remains stable.
- One CSS style query removes the collapsed footer using Obsidian's existing `--keyboard-height` property. No new listeners, viewport detection, observers, settings, persisted UI state or cross-plugin dependency.
- Keyboard dismissal restores the footer even when the search input remains focused. Desktop, other food tabs and an expanded review retain their controls.

Patch release for food-logger interaction fixes. Minimum Obsidian **1.12.0**. Existing 3.4.0 Controller connection handoffs are preserved; no migration.

## Compatibility and limits

CSS style queries require iOS/WebKit 18+ or a supporting Android WebView; older engines retain the existing visible footer. This uses the standard CSS facility described in [WebKit's Safari 18 announcement](https://webkit.org/blog/15865/webkit-features-in-safari-18-0/). Test-vault DOM/CSS checks simulated keyboard state; physical iPhone keyboard interaction was not exercised.

Tested in **Obsidian Plugin Test Vault**, ready for the user's **BRAT pull**. Publication does not install it in production.
