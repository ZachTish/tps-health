# TPS Health 0.1.3

## Release intent

This is the first GitHub release of the existing `0.1.3` plugin for BRAT installation and **Latest**-release tracking. The packaging work synchronizes release metadata without changing shipped runtime behavior or health-log data formats.

## Included behavior

- Daily-note-backed food, meal, activity, and workout logging with reusable food, recipe, exercise, and workout-plan notes.
- Food search, barcode scanning, nutrition rollups, guarded Describe workflows, Activity/Food Log Bases integration, and mobile-aware UI.
- Private-repository installation through BRAT with a fine-grained GitHub token limited to **Contents: Read-only**.

## Compatibility

- Minimum Obsidian version: `1.12.0` because device-local provider credentials use Obsidian SecretStorage.
- Desktop and mobile are supported.
- No migration is required from the existing `0.1.3` runtime; package-lock metadata is synchronized to the already-declared version.

## Validation

- `npm test`: passed `97/98` tests; the one skipped test is the intentionally gated live USDA integration, and the nested production build passed.
- Required separate `npm run build`: passed TypeScript and esbuild production bundling.
- Test-vault deployment: `[runtime-deploy] target=test ... unchanged`; the final source artifacts are byte-identical to the installed test runtime.
- This release candidate is prepared from the test-vault source and has not been promoted to production by this packaging pass.

## Known limitations

- Private BRAT installs require the GitHub token on each device; never store that token in the vault or repository.
- BRAT does not transfer SecretStorage credentials or plugin settings between devices.
- External nutrition providers can return incomplete data; provider foods remain review candidates rather than authoritative records.
- Apple Health transport and deduplication are not implemented, and the optional live USDA check is not run without an explicit test key.
