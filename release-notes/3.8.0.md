# TPS Health 3.8.0

Adds a dedicated **Health dashboard**, opened by **TPS Health: Open health dashboard** or the heart-pulse ribbon icon. Reopening reuses its existing tab.

- Select any day or return to Today. Food/activity logging, workout start and recipe creation use that selected date.
- Compare logged calories with the existing BMR × activity-factor estimate; see macro rings/tables, nutrient totals/goals and contributing foods.
- Review logged foods, activity and workout sessions with their existing source/edit/remove actions. Steps and logged activity calories appear with the daily activity summary. Workouts retain the existing session/inline-set flow.
- Review seven days of intake, estimated burn, differences and activity, plus logging coverage and steps. Days without logs are not treated as zero intake. Burn uses current settings and does not count exercise twice.
- Responsive phone/tablet layout, wrapping actions, usable touch controls and restored keyboard focus after date changes.

Minor release for a new view/command. Minimum Obsidian **1.12.0**. Requires Health storage **Atomic notes** for the dashboard; legacy mode displays an explanation and does not scan/import existing notes. No persisted settings/schema/API changes or migrations. Existing Health blocks and settings navigation remain. Date/disclosure state is transient. The view reuses the current native index and scoped daily-component subscriptions; no new vault listener, cache, poller or automatic writer.
