# TPS Health 0.23.2

## Daily Note recognition repair

- The Native Health dashboard now recognizes an explicitly typed Daily Note (`kind: dailynote`) from an exact ISO `date` or `scheduled` property when Templater or Notebook Navigator stores it outside Core Daily Notes' current path pattern.
- Core Daily Notes remains the first authority. The fallback rejects unrelated scheduled notes, untyped date-shaped notes, and invalid dates.
- Dashboard actions retain the containing note's resolved date for food, activity, and workout creation.

## POC configuration alignment

- The Native POC's Core Daily Notes and Notebook Navigator now share the production-style `YYYY/YYYYMMDD` path.
- The Templater rule and Daily Note template accept both compact and legacy ISO filenames, preventing duplicate or invalid future Daily Notes.

## Compatibility

- No stored-record, settings, or public API migration is required.
- Native and Legacy Health storage remain compatible.
- Minimum Obsidian: 1.12.0.
