# TPS Health 0.25.0

## A calmer, stable food logger

- The general **Log food** workflow opens on Search on every launch, even when it restores an existing tray. Dedicated Scan and Quick add commands retain their direct routes.
- The tray's primary action now says exactly what will happen: **Log 1 food** or **Log N foods**. The tray remains above search results and uses a flatter, quieter layout with fewer nested outlines.
- Adjusting a quantity or unit updates only that row's macros and the tray summary. TPS Health no longer destroys and rebuilds the tray for routine edits, so keyboard focus, scroll position, and row geometry remain stable.
- Macro pills stay on one horizontally contained line, status messaging reserves a predictable height, and mobile tabs and controls use fixed touch-friendly layouts that do not reflow as values change.

## Reliable active-workout recovery

- Starting, resuming, finishing, and discarding a native workout reconcile the saved active state against the stable workout-session identity before mutating anything. Moved sessions recover; finished or missing ghosts clear with a truthful notice; duplicates and a still-warming index fail closed.
- Active ownership is compared as one state snapshot so a synced or locally replaced workout cannot be overwritten by an older finish, discard, or recovery operation.
- The Daily Activity block persistently shows a valid active workout with elapsed time plus one accessible Resume/Finish action pair. Start workout appears only when no valid active session exists.

Existing pending trays, records, settings, provider behavior, storage modes, commands, and public APIs require no migration. Minimum supported Obsidian remains 1.12.0.
