# TPS Health 0.34.1

This patch restores the live-workout controls that were functionally present but pushed off-screen in narrow and mobile panes.

## Changes

- Narrow workout tables now keep Set, Reps, Weight, Rest, Complete, and the set menu visible without horizontal scrolling. RPE and set type remain visible on wider panes.
- Replaced the unlabeled completion checkbox with a clear `Complete` / `Done ✓` button, including pressed state, keyboard behavior, saving feedback, and mobile touch sizing.
- Completing a normal set starts the next open set's rest countdown. Drop sets advance immediately and start rest only after the final member; supersets retain their final-exercise timing rule.
- Added a direct **Add drop set** menu action that creates and links the new set atomically. Repeating it extends the existing chain, while **Link existing drop sets…** supports explicit grouping.
- Empty-body native workout notes now mount their single workout surface directly in Reading mode; duplicate suppression keeps the later Markdown-render pass from producing a second copy.

## Compatibility and migration

- Backward-compatible patch release; no settings or workout-note migration is required.
- Existing nested `session` data, set IDs, superset/drop-set group IDs, and workout APIs remain compatible.
- Minimum supported Obsidian version: 1.12.0.

## Validation

- Focused native-workout tests cover direct creation from a one-set exercise, extending a chain, immediate drop-set sequencing, delayed rest, completion undo, supersets, narrow layout, and visible completion semantics.
- All 273 declared checks ran: 272 passed and only the credential-gated live USDA request skipped. TypeScript and the mandatory separate production build passed, and the final source artifacts match the isolated test runtime byte-for-byte.
- Interactive Obsidian 1.13.7 QA used a roughly 360 px workout pane in both Live Preview and Reading mode. The set menu exposed **Add drop set**, repeated additions extended the chain, the labeled completion control stayed visible, the intermediate drop did not start rest, and completing the final drop started the countdown on the next normal set. An empty-body session rendered once in Reading mode. Test settings and layout were restored after reload, and the synthetic workout/exercise notes were moved to `_archive`.
