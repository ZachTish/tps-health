# TPS Health 0.12.4

TPS Health 0.12.4 repairs the broken iPhone food-logging modal.

## User-visible changes

- Saved and search results no longer inherit Obsidian's oversized, vertically stacked mobile Setting controls.
- **Add** and **Choose amount** remain together as compact, full-width touch targets; provider results place **Create from this** on a separate full row when space is narrow.
- Scan, Search, Saved, Describe, and Quick add remain fully visible in a stable two-row phone grid instead of collapsing into a thin horizontal strip.
- Food result cards expose valid labeled-group semantics with independent buttons, avoiding nested button behavior on touch and accessibility input.

## Compatibility and migration

- No settings migration.
- No note-schema migration.
- No public API change.
- Minimum supported Obsidian version remains 1.12.0.

## Validation

- Full declared suite: 173 passed, 1 credential-gated live USDA check skipped, 0 failed (174 total).
- TypeScript no-emit and diff checks passed.
- The final production build deployed only to the isolated `Obsidian Plugin Test Vault` runtime.
- Obsidian 1.13.7 rendered the rebuilt Saved-food cards with compact title, serving, macro, and action rows after hot reload. Its accessibility tree exposed every card as a labeled group containing separate Add and Choose amount buttons.
- Mobile regressions require a two-row tab grid, 44 px coarse-pointer controls, container-driven result stacking, and no generic Setting wrapper inside a result card.
- Production was not changed. This release is ready for the user's BRAT pull after publication.
