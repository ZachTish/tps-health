# TPS Health 3.7.1

Improves cramped, inconsistent Health forms on phones and tablets while preserving the existing logging and workout workflows.

- Shared dialog sizing removes the old top offset, duplicate padding and empty header. Tablet food search uses the available width, up to 860 px.
- Recipe creation follows name, ingredients, yield, nutrition preview, optional search aliases, then Create/Save. Add ingredient appears before the list; ingredient cards share rows on wider screens.
- Ingredient search shows amount controls after selection. Yield fields use decimal keyboards, and weight mode hides the irrelevant servings field.
- Food, activity, entry and existing workout-set dialogs share responsive fields, readable inputs, visible keyboard focus, usable touch targets and sticky primary actions. Empty exercise suggestions occupy no space.
- Workout sets stay together in the existing workout. No per-set pages or additional navigation steps. Search, tray highlighting, keyboard-hidden food actions, save handlers, nutrient calculations and storage are preserved.

Patch release for layout defects. No settings, data, API or migration changes; no new listeners, observers, timers or caches. Settings destinations remain unchanged. Minimum Obsidian **1.12.0**.
