# TPS Health 3.1.3

Adding a food now opens the review tray immediately. The tray has its own primary **Log N foods** button, so logging no longer requires returning to the search page.

- Search and barcode additions expand review, including increasing the quantity of a food already selected. Focus moves into review; closing it returns to the preserved search query/results.
- Tray and search actions share the existing logging path and display consistent count, busy and disabled states. Duplicate-submit, invalid-unit, consumed-date, draft ownership and partial-failure protections remain.
- Tray actions wrap on narrow layouts and have a minimum 44 px height.

Backward-compatible patch. No settings, draft format, nutrition calculation or API migration. Minimum Obsidian **1.12.0**. Desktop and mobile supported; physical iOS acceptance remains user testing.
