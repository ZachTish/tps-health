# TPS Health 0.27.0

## Bases-style dates for Health blocks

- `tps-health-macros`, `tps-health-activity`, and `tps-health-daily` accept one Bases-style date equality filter.
- Blocks can resolve `today()`, `now().date()`, fixed ISO dates, dates from `this.file.name` / `this.file.path`, and frontmatter dates through `this.<property>` or `this.file.properties.<property>`.
- Bases duration arithmetic such as `today() - "1d"` and the standard `filters:` / `and:` wrapper are supported.
- Empty blocks keep their existing Core Daily Note behavior. An explicit valid selector can be embedded in an ordinary Markdown dashboard note.
- Invalid, unresolved, or multiple date selectors fail visibly, and dashboard actions always inherit the displayed day.

This is a backward-compatible feature. Existing records, settings, public APIs, storage modes, and block names require no migration. Minimum supported Obsidian remains 1.12.0.
