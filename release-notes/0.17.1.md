# TPS Health 0.17.1

TPS Health 0.17.1 fixes reusable exercise and food destination editing and gives every reusable-note destination a searchable vault-folder chooser.

## Changes

- Folder text fields now commit the complete path on blur/change or Enter instead of normalizing and saving every intermediate keystroke.
- Workouts, workout plans, exercises, foods, and recipes each have a searchable folder action that selects an existing vault folder without requiring exact path entry.
- The settings copy now states exactly which newly created entities use each destination. Food notes use the food destination; recipes and meals use the recipes destination.
- Existing reusable notes are not silently moved or rewritten when a destination changes. They remain resolvable through their existing metadata, tag, and folder identification rules.
- Folder changes emit a compact settings diagnostic containing only the setting key and normalized vault-relative destination.

## Compatibility and migration

- No settings migration, note-schema change, or public API change is required.
- Existing configured paths remain valid and are normalized by the existing settings pipeline.
- Minimum supported Obsidian version remains 1.12.0.
