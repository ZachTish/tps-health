# TPS Health 0.14.0

TPS Health 0.14.0 makes Describe omission-safe and substantially more resilient to Gemini structured-output failures.

## User-visible changes

- Describe first extracts every requested food with a stable item ID, then independently reviews portions and nutrition.
- Every extracted ID must appear exactly once before the tray is built. Missing, low-confidence, calorie/macro-inconsistent, physically overfilled, or impossible-density items are retried individually.
- If an item still cannot be estimated, it remains visible in the editable tray with zero confidence and a needs-review notice instead of silently disappearing.
- Extraction, review, and repair use small flat schemas and separate durable Gateway job IDs. The extracted checkpoint survives closing Obsidian and resumes without creating duplicate tray data.
- Local recovery now includes a large Honeycrisp apple as one 242 g apple at about 126 kcal. `4 yogurts and a large honeycrisp apple` is covered through parsing, missing-item repair, and deterministic fallback.

## Reliability and safety

- The previous nested one-pass schema produced a Gemini HTTP 400 in the observed production queue. The new schemas remove that nesting and isolate failures to one bounded stage or item.
- Nutrition auditing checks confidence, calorie/macro agreement, macro mass against estimated weight, and impossible calorie density before accepting the result.
- Describe remains review-first: it creates no reusable food note and writes nothing to a Daily Note until the user chooses **Log selected**.
- Request text and nutrition-label images retain their existing privacy boundaries; diagnostics contain counts and outcomes rather than meal text or credentials.

## Compatibility and migration

- No settings migration.
- No note-schema migration.
- No public API change.
- TPS AI Gateway 0.4.0 or newer remains required for Gemini Describe.
- Minimum supported Obsidian version remains 1.12.0.

## Validation

- Final declared suite: 177 of 178 checks passed; the only skip was the credential-gated live USDA check.
- Focused coverage forces Gemini extraction and review to omit the apple from `4 yogurts and a large honeycrisp apple`, then verifies deterministic reconciliation restores both requested foods, retries the missing apple, and produces the complete editable tray.
- The mandatory separate production-mode build was byte-stable after deployment to the isolated test runtime. Source and runtime `main.js`, `manifest.json`, and `styles.css` are byte-identical.
- UI reload was intentionally not attempted because the only open Obsidian window was the production vault. The safety guard prevented test automation from operating there.
- Production was not changed by this release workflow.
