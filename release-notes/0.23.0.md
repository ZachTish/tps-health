# TPS Health 0.23.0

## Reusable Health notes can live at the vault root

- `/` is now a supported destination for workouts, workout plans, exercises, foods, and recipes.
- Root destinations create new notes directly in the vault root and no longer fall back to the default `Health/...` folders.
- Root is never used as a broad Health identity signal; typed frontmatter and tags continue to distinguish Health notes from unrelated root notes.
- Existing files are not moved and Native-record entry placement remains owned by GCM's native-record layout.
