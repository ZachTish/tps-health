# TPS Health 0.23.4

## Base-style Daily Nutrition dashboard

- The inline Daily Nutrition experience now fits naturally between core Base embeds instead of appearing as a separate oversized card.
- A compact Base-like header shows the entry count and calorie total, with accessible icon actions for adding food, logging activity, and starting a workout.
- Nutrition metrics use aligned Metric, Current, and Goal columns with restrained row separators and progress bars.
- Empty and populated states share the same stable layout. Date targeting, Health actions, record storage, and schemas are unchanged.

Minimum Obsidian: 1.12.0.

## Validation and artifacts

- Validation: the complete declared `npm test` suite, its production build, a separate final `npm run build`, the focused Daily Nutrition suite (6/6), TypeScript, and `git diff --check` passed. The broad Health harness passed 162 tests with one credential-gated live integration check skipped.
- Test-vault/POC QA: the exact release artifacts were deployed to both vaults. After a cold POC reload, the populated and empty Daily Nutrition states rendered as compact Base-like tables between the neighboring Agenda and Food Entries Bases, with stable layout and reachable header actions.
