# TPS Health 0.16.0

TPS Health 0.16.0 restores and expands linked workout sequencing while making the active workout visible to GCM time tracking without creating a second Daily Note section.

## Changes

- Replaced the adjacent-row superset shortcut with an explicit exercise chooser that lists the other exercises in the workout and can add a new exercise.
- Replaced the previous-row drop-set shortcut with an explicit set chooser that lists the other sets in the exercise and can add a new set.
- Added compact, mobile-friendly visual group cues in Reading mode and Live Preview.
- Added deterministic completion traversal: finish the current drop chain, rotate through linked superset exercises, then return for the next round.
- Active workouts now attach GCM time tracking to Health's existing linked workout task. Reload reuses the exact timer; finish and discard stop only that session.
- GCM timer integration uses no-workspace mode, so it does not create `## Scheduled`, `## Time Tracking`, a second workout heading, or a session notes block.

## Compatibility and migration

- Existing `superset` and `dropSet` inline IDs remain compatible; no workout-note or settings migration is required.
- TPS Global Context Menu 1.35.0 or newer is required for no-workspace timer integration. Workout logging remains available when GCM or GCM time tracking is disabled.
- Minimum supported Obsidian version remains 1.12.0.

- The complete declared suite passed: 189 checks passed, one credential-gated live USDA check was skipped, and zero checks failed.
- A separate final production-mode build passed and deployed byte-identical `main.js`, `manifest.json`, and `styles.css` artifacts to the isolated test runtime.
- Live Preview QA started a blank workout, logged multiple exercises, selected an arbitrary exercise through the superset chooser, selected an existing set through the drop-set chooser, and confirmed compact `SUPER A` and `DROP A` group cues. The synthetic Daily Note, workout, and exercise notes were then moved to Obsidian's recoverable trash.
- The test vault had GCM time tracking disabled, so UI QA did not mutate that setting or create a timer record. Automated integration coverage verifies no-workspace start/reload/finish/discard ownership against an enabled GCM API, including exact-session stop and unrelated-timer preservation.
