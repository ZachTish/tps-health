# TPS Health 6.0.1 — Write only tracked food-log nutrients

Food logs previously persisted all supplied nutrition regardless of Health's selected goals. Creation, explicit portion edits and linked-definition saves now filter nutrients at their existing writer boundary. Only selected nutrient goals (including Track only) write mapped nutrient fields. Unselected B12 is absent; selecting it permits its configured property. No separate storage selection or migration is added.

Reusable food and recipe definitions stay complete. Existing unselected log values remain historical and are not rewritten or removed; this release performs no vault cleanup. Read-only linked nutrition can still calculate other known nutrients. Selected known zeroes survive. An untracked-only definition change performs no linked-log mutation. Classifications, IDs, property names, destination navigation and mobile controls remain configurable/unchanged. Settings explain the policy. Requires Obsidian 1.12.0 or newer.

This is a backward-compatible correctness patch. There are no new scan/poll/retry/cache owners. Downgrading restores the old all-nutrient write policy; it cannot restore values deliberately removed elsewhere. Physical iPhone verification is not claimed.
