# TPS Health 6.2.0 — Configurable primary totals and nutrient bars

Select a nutrient under **Food & goals → Nutrient targets**, choose **Show in primary totals** and **Show in nutrient bars**, and **Save target**. Protein, carbs and fat now appear in both rings and lower bars by default. Any tracked nutrient, including registered custom nutrients, can appear in both, one or neither display. Calories remain primary-only by default. Display choices do not change tracking membership, stored properties, targets or totals.

- Primary totals follow the existing Rings/Rows setting; lower bars follow the existing hidden/collapsed/expanded Nutrients control and explicit block overrides.
- Both surfaces reuse the same metric/targets/colors/contributions. No double counting, note rewrite, provider call or new scan/timer/cache.
- Primary rings wrap at four columns (two on narrow layouts). Native switches have nutrient-specific accessible labels and use the existing Save target action.
- Additive optional booleans on existing goal settings and public render configs; unchanged keys/defaults/commands, no note migration. Five settings destinations and disclosure depth retained.

Minimum Obsidian: **1.12.0**. This additive minor release is tested in Obsidian Plugin Test Vault and is a BRAT handoff, not a production installation. Physical iPhone acceptance remains separate.
