# TPS Health 0.18.1

This backward-compatible patch makes the activity logger describe the selected storage architecture accurately.

## Fix

- Native mode now says that logging creates one typed activity record and does not rewrite the Daily Note body.
- Legacy mode keeps the existing Daily Note storage description.
- Record schemas, nutrition/workout behavior, settings, and public contracts are unchanged.

Minimum Obsidian: 1.12.0. GCM 1.38.0 or newer is required for native mode. Tested in the isolated test vault and the blank TishOS Native POC, and ready for the user's BRAT pull.
