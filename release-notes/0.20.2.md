# TPS Health 0.20.2

This patch closes two date-context gaps found during end-to-end native Daily Note QA.

## Food tray isolation

- A Daily Note logger never restores a saved tray that belongs to the context-free **Log food** command.
- A context-free logger likewise never restores a tray owned by a specific Daily Note.
- Logging or clearing one of those trays uses compare-and-swap ownership and cannot delete the other tray.
- Existing food, activity, and workout record schemas are unchanged.

## Root Daily Notes on mobile

- Obsidian Mobile's `.` Core Daily Notes folder sentinel is normalized to the vault root.
- Root `YYYY-MM-DD` notes now resolve the same way as desktop root Daily Notes, so the native Health dashboard and its date-scoped actions render reliably.
- Explicit past or future Daily Note dates remain authoritative for food, activity, and workout creation.

## Compatibility

- No setting, schema, API, or legacy-storage migration is required.
- Minimum Obsidian: 1.12.0.
