# TPS Health 0.15.4

TPS Health 0.15.4 corrects the remaining mobile lockup in Add exercise. Version 0.15.3 reduced the catalog scan cost but still made the full-screen picker wait for that scan before offering a useful action.

## What changed

- The exercise picker paints immediately with a search field, loading state, and explicit Cancel button.
- Typing a new exercise name creates the `Use “name”` action synchronously, before saved-exercise discovery finishes.
- Picker selection uses Obsidian's exact link index or a valid cached exercise entry and can create a new note without waiting for another full-vault catalog build.
- Background discovery yields before scanning and every 12 Markdown files, rather than every 40 files.
- A malformed metadata entry is skipped instead of rejecting the entire exercise catalog.
- Mobile does not automatically focus the search field or open the software keyboard when the picker appears.
- Search errors remain visible and recoverable: users can still add the typed name or cancel the modal.
- Exercise result buttons use one click route rather than registering both pointer and click handlers.

## Compatibility

- Minimum Obsidian version: 1.12.0.
- No API, settings, or Markdown migration is required.
- Existing exercise notes, active workouts, and the 0.15.3 folder normalization remain compatible.

## Validation

- Focused regressions cover fail-open modal controls, responsive exact-note reuse, direct new-note creation with full-vault scanning forced to fail, small scan chunks, cache reuse, active-workout insertion, and the existing workout command contract.
- The full declared suite passed 183 tests with one credential-gated live-USDA skip and no failures. The mandatory separate production-mode build also passed.
- In the isolated test vault, the deployed picker visibly opened in its loading state with a working Cancel button, typing immediately exposed `Use “Fail Open Mobile Curl”`, and selecting it inserted a workout row without locking Obsidian. The synthetic workout was discarded and its exercise note moved to `_archive` afterward.
- Production 0.15.3 was inspected narrowly for diagnosis. Its active Daily Note remains a valid 22-line bounded workout with zero set rows; production was not modified, deployed, or reloaded.
