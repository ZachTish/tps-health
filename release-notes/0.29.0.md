# TPS Health 0.29.0

## Macro rings and food contributions

- Add `style: rings` to `tps-health-macros` or `tps-health-daily` to show compact progress rings for calories, protein, carbs, and fat against the configured Health goals.
- Add `foods: collapsed` for an optional disclosure of the food-entry records behind the selected day's totals, or `foods: expanded` to open it initially.
- Contribution rows show the logged title, calories, consumed amount, and P/C/F snapshot and open the owning entry note from the title.
- Existing empty blocks and date filters remain compatible: the table is still the default and the food list remains hidden unless requested.

The new presentation is responsive in narrow panes and on mobile, retains keyboard and screen-reader semantics, and does not change stored notes, records, settings, or public APIs. This is a backward-compatible feature release. Minimum supported Obsidian remains 1.12.0.
