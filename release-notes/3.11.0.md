# TPS Health 3.11.0 — Seven-day glance on the Health dashboard

The native Health dashboard now shows a compact, selectable seven-day glance immediately above the selected day's energy, macros, foods, nutrients, and activity. The existing detailed seven-day comparison remains below. Day cards scroll horizontally in narrow panes and on phones, and selecting a day focuses the date control. During initial indexing, the glance shows a loading state and provisional food/activity labels instead of a misleading zero.

The glance and detailed comparison use the same seven-day indexed result. No extra record or body reads, listeners, cache, persisted state, settings, commands, note format, or migration were added. This is a backward-compatible dashboard feature; minimum Obsidian remains **1.12.0**. It was tested in **Obsidian Plugin Test Vault** and is ready for the user's BRAT pull. Production was not modified.

## Validation

- Focused dashboard tests cover section order, date selection and focus, loading/indexing labels, mobile card CSS, and one weekly result per render: seven food and seven activity day lookups, with no added source reads. These are harness counts, not installed-device timings.
- The final versioned declared `npm test` suite passed **606** checks, failed none, and skipped one optional live USDA check without its credential. TypeScript and a separate final `npm run build` passed; the final build reported the deployed Test artifacts unchanged.
- In the exact `Obsidian Plugin Test Vault` window, the reloaded installed dashboard showed the glance before daily detail. Selecting September 26 showed the saved 380 kcal and two entries; Today returned to October 2. At half-width and a mobile-like zoomed panel, day cards remained readable and horizontally scrollable. The viewport and zoom were restored. No note, setting, or outbound-provider change was made during UI QA. The runtime `data.json` predates the build and was not replaced.
- A physical iPhone was not tested. The glance covers only seven days and retains the existing detailed view and its current data model.
