# TPS Health 8.0.1 — Direct food setup and progressive search

Food-provider configuration now opens directly under Health → Integrations & advanced → Food databases, even when Controller is disabled. The existing USDA reference ordering and Open Food Facts identification controls are reused. No settings schema, credentials, defaults, note format or provider request routes change. The existing renderer API remains compatible; AI-assisted Describe retains its current optional connection handoff.

Food logging and recipe search show saved matches and each completed provider without waiting for the slower provider. Existing query tokens reject old-query, closed-modal and selection-invalidated responses. Search-result updates do not replace the selected food or quantity/unit controls. Choosing a recipe ingredient clears the search busy state so the button remains usable. Programmatic search still returns one complete result with the same ranking and deduplication, independent of arrival order. Existing provider timeouts, request counts and serving/nutrition readers are retained.

This patch removes one unnecessary settings handoff and disposes the existing panel when its page closes or rerenders. It adds no watcher, cache, provider request, startup migration or automatic writer. The README is a current specification; the prior narrative remains in Git history and existing release/reference material. A stale documentation assertion that the removed Shortcut mailbox remained supported is corrected; runtime scanner coverage remains unchanged.

Validation uses actual plugin search methods, both modal search/render methods and recipe selection with synthetic Obsidian/DOM/provider boundaries. It covers both provider arrival orders, usable local matches, unchanged selected portions, stale queries, closing/tab changes, timeouts, one request per provider and complete-result API compatibility. Existing nutrition/serving and indexed-usage operation-count suites remain. Initial failures and exact validation/artifact receipts are retained outside the vault; source checks are not installed timing evidence.
