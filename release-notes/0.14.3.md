# TPS Health 0.14.3

TPS Health 0.14.3 keeps the food tray within reach while searching and adding foods, especially on phones.

## User-visible fixes

- The selected-food tray now sits directly below the active logging controls and above the food-results list.
- Long Recent and frequent or search result lists can no longer push selected items to the bottom of the modal.
- After Add, Health reveals the compact tray header using nearest-edge scrolling, making the selected count, combined macros, and **Log selected** action immediately reachable without jumping to the end of the full tray.
- Restored and Describe-generated trays use the same placement on desktop, narrow panes, and mobile.

## Compatibility and migration

- No settings migration.
- No note-schema or data migration.
- No public API change.
- Minimum supported Obsidian version remains 1.12.0.

## Validation

- Final declared suite: 180 of 181 checks passed; the only skip was the credential-gated live USDA check.
- Focused coverage verifies tray-before-results DOM order, reveal-after-search-reset sequencing, nearest-edge header scrolling, and the existing durable tray behavior.
- The final artifacts deployed only to the isolated test runtime. Production was not accessed.
